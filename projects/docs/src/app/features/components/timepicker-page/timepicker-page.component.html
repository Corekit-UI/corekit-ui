Timepicker

An input for a time of day, with a popup to pick it in. The value is a date carrying the picked time: typing moves the time of the day the value already points at, leaving that day alone.

Turning the columns of the popup only moves the time it is showing. Nothing reaches the value until Set keeps it, and Cancel leaves it as it was.

Basic

Type a time the way the locale writes it, e.g. 2:30 PM or 14:30 . A bare hour is a time of its own, so 9 reads as nine in the morning.

Reactive form, boundaries and validation

min and max compare the time alone, so the day they fall on is of no consequence. The columns of the popup list only what they leave within reach.

Time selector

The columns of the popup, on their own. The clock comes from the locale, which decides both how the hours are numbered and whether there is a day period column at all.

Picked: {{ selectorTime() }}

Forcing a clock

Pass hourFormat to lay the columns out on a 12-hour or a 24-hour clock whatever the locale keeps time on.

Picked: {{ clockTime() }}

Boundaries in the columns

A column lists only what is within reach. An hour stays on the list while any of its minutes is within the boundaries, and a half of the day while any of its hours is, so the minute column grows and shrinks as the hour at either end of the range is picked.

Stepping past a boundary pulls the time back to it, which is what happens when an hour only lets some of its minutes through.

Picked: {{ boundedTime() }}

Opening time

A popup opened with nothing picked has to start somewhere, and the current time is where it starts. Pass startAt to open it somewhere else, and project any content into the toggle to replace its clock.

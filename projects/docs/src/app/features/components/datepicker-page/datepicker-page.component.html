Date range picker

Two inputs share one frame, one popup and one set of boundaries. Pick the start in the calendar, then the end — the popup closes once the range is complete. Typing works too, and so does moving the caret between the halves with the arrows or Backspace .

Custom selection strategy

Provide CK_DATE_RANGE_SELECTION_STRATEGY to decide how the picked dates turn into a range and what the calendar previews. This one hands out five days at a time — provided on the component around the picker, so the pickers above keep the default behavior.

Date range in an inline calendar

The calendar reports every picked date and leaves composing the range to whoever owns the selection — here it is the page itself, using the default selection strategy. Hover or arrow around the grid after picking the first day to see the range being previewed, and press Escape to abandon it.
